# Reporting software security issues

For a suspected vulnerability, request a private contact channel from the repository owner through a GitHub issue titled “Private security contact requested”. Keep the initial request free of sensitive details. Share the affected QCF version or commit, environment, impact and a minimal reproduction once a private channel is agreed. [Repository issues](https://github.com/ShuRaAtum/qcryptforge/issues).

Ordinary circuit-correctness issues can be reported publicly with a failing input and expected output. QCryptForge is an experimental research library and is unsuitable for protecting production data.
